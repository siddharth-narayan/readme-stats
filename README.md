# readme-stats
Generate beautiful tiles for your GitHub READMEs

You can also control for light/dark mode with query parameter `theme`: appending `?theme=github-light` generates a light mode colored card, and `?theme=github-dark` a dark colored one

[![Readme Card](https://readme-stats.novaphaze.com/repos/siddharth-narayan/readme-stats?theme=github-light)](https://github.com/siddharth-narayan/readme-stats)
[![Readme Card](https://readme-stats.novaphaze.com/repos/siddharth-narayan/readme-stats?theme=github-dark)](https://github.com/siddharth-narayan/readme-stats)

Appending `#gh-light-mode-only` or `gh-dark-mode-only` to your image's link will allow it to appear in only light/dark mode appropriate to the user's theme. The cards in this README appears as your system theme by doing this.

### Repositories - `/repos/<username>/<repo-name>`
```markdown
[![Readme Card](https://readme-stats.novaphaze.com/repos/siddharth-narayan/readme-stats)](https://github.com/siddharth-narayan/personal-site)
```

Generates the following:

[![Readme Card](https://readme-stats.novaphaze.com/repos/siddharth-narayan/readme-stats?theme=github-light)](https://github.com/siddharth-narayan/readme-stats#gh-light-mode-only)
[![Readme Card](https://readme-stats.novaphaze.com/repos/siddharth-narayan/readme-stats?theme=github-dark)](https://github.com/siddharth-narayan/readme-stats#gh-dark-mode-only)
