# readme-stats
Generate beautiful tiles for your GitHub READMEs

```markdown
[![Readme Card](https://github-readme-stats-535890345750.us-south1.run.app/repos/siddharth-narayan/readme-stats)](https://github.com/siddharth-narayan/personal-site)
```

Generates the following:

[![Readme Card](https://github-readme-stats-535890345750.us-south1.run.app/repos/siddharth-narayan/readme-stats?theme=github-light)](https://github.com/siddharth-narayan/personal-site#gh-light-mode-only)
[![Readme Card](https://github-readme-stats-535890345750.us-south1.run.app/repos/siddharth-narayan/readme-stats?theme=github-dark)](https://github.com/siddharth-narayan/personal-site#gh-dark-mode-only)


You can also control for light/dark mode with query parameter `theme`: appending `?theme=github-light` generates a light mode colored card, and `?theme=github-dark` a dark colored one

[![Readme Card](https://github-readme-stats-535890345750.us-south1.run.app/repos/siddharth-narayan/readme-stats?theme=github-light)](https://github.com/siddharth-narayan/personal-site)
[![Readme Card](https://github-readme-stats-535890345750.us-south1.run.app/repos/siddharth-narayan/readme-stats?theme=github-dark)](https://github.com/siddharth-narayan/personal-site)

Appending `#gh-light-mode-only` or `gh-dark-mode-only` to your image's link will allow it to appear in only light/dark mode appropriate to the user's theme. The first card in this README appears as your system theme by doing this.
